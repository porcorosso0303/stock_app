# 盯盘脑图设计

## 目标

在现有单股调研功能旁增加“盯盘脑图”。用户通过界面维护一棵自定义分类树，股票作为叶子节点。脑图展示股票行情快照，并汇总分类节点下所有可用股票的平均涨跌幅。

## 当前范围

包含：

- 左侧功能列表中的“单股调研”和“盯盘脑图”入口。
- 点击“盯盘脑图”后，右侧完整工作区切换为脑图面板，不与调研工作区同时显示。
- 创建一个分类作为脑图顶层节点。
- 右键点击节点后，通过菜单添加子分类或股票，并编辑或删除节点。
- 添加股票时按名称搜索 A 股候选，选择后保存标准 `secid`。
- 股票节点显示名称、当日走势曲线和实时涨跌幅，分类节点只显示名称。
- 股票走势曲线中间显示零轴虚线，整条线按最新涨跌幅统一着色：上涨显示红色，下跌显示绿色；右侧涨跌幅数字按涨跌显示红色或绿色。
- 鼠标悬停节点时，通过提示查看股票价格、涨跌幅或分类平均涨跌幅。
- 左键点击展开状态的分类节点后回缩；回缩态节点右侧紧贴显示小加号，再次左键点击后展开。
- 在脑图展示区域按住鼠标左键拖动，向任意方向平移脑图；拖动时显示抓取光标。
- 节点按横向脑图排列。父节点与直接子节点之间使用独立的平滑曲线连接，清晰展示分叉关系。
- 打开脑图后优先读取同日本地行情缓存，缺失或隔日时拉取当天走势和快照，并每 15 秒刷新一次。
- 行情失败时显示“暂无行情”，不伪造数据。

暂不包含：

- 多日历史走势回放。
- 拖拽排序。
- 多棵树。
- 交易所认证行情或交易功能。

## 数据模型

软件根目录 `user_data/` 增加：

```text
watch-tree.json
watch-quotes-cache.json
```

顶层节点必须为分类。分类节点包含 `id`、`type`、`name` 和 `children`。股票节点包含 `id`、`type`、`name` 和东财 `secid`。

`secid` 格式为 `<market>.<code>`，例如：

- 沪市贵州茅台：`1.600519`
- 深市宁德时代：`0.300750`

主进程保存前校验节点类型、非空名称、重复 `id` 和 `secid` 格式。

## 行情

主进程通过东财公开搜索端点按名称查询 A 股候选，通过公开行情快照端点获取股票价格和涨跌幅，并通过公开分时端点获取当天走势。Renderer 不直接联网，只通过 preload 暴露的受限 IPC 搜索股票和请求缓存感知行情。

公开端点无需密钥，但不是交易所认证行情。请求失败、股票不存在或返回格式异常时，该股票显示“暂无行情”。分类平均值只统计当前有涨跌幅数据的叶子节点。

同日缓存命中时，应用直接用 `user_data/watch-quotes-cache.json` 渲染脑图，不重新拉取初始走势。隔日启动时，旧缓存失效，应用重新拉取新一天数据。刷新失败但同日缓存存在时，界面继续展示缓存数据。

## IPC

Preload 增加：

- `getWatchTree()`
- `saveWatchTree(config)`
- `getWatchQuotes(secids)`
- `getWatchMarketData(secids)`
- `refreshWatchMarketData(secids)`
- `searchStocks(query)`

Main Process 对保存内容和行情请求参数再次校验。

## 手工验收

1. 点击左侧“盯盘脑图”，确认右侧切换到脑图。
2. 在空白区域点击鼠标右键，创建分类“科技股”。
3. 右键点击“科技股”分类，添加“软件”“硬件”分类。
4. 右键点击分类节点，添加股票；输入名称并从 A 股候选中选择。
5. 确认股票节点显示名称、走势曲线和右侧涨跌幅；整条走势线和涨跌幅数字按最新涨跌幅统一显示红色或绿色。
6. 左键点击分类节点，确认子树展开或回缩。
7. 在展示区域按住鼠标左键拖动，确认可以向任意方向平移。
8. 重启应用，确认配置和同日走势缓存仍然存在；隔日启动时重新拉取新一天数据。
