# 盯盘脑图持仓股标记设计

## 目标

允许用户在股票节点编辑菜单中设置“持仓股”属性，并在脑图中通过醒目的股票名称样式快速识别持仓股票。

## 数据模型

在 `WatchTreeStockNode` 增加可选布尔字段：

```ts
isHolding?: boolean;
```

- `true` 表示持仓股。
- `false`、字段缺失均表示非持仓股。
- 为保持配置简洁，非持仓股保存时省略该字段。
- 字段随 `watch-tree.json` 持久化，并自然进入现有脑图导入、导出流程。
- 脑图配置校验只接受布尔值；非布尔值视为无效配置。

## 编辑交互

沿用现有股票节点编辑对话框，在“行业地位”设置附近增加“持仓股”下拉列表：

- 否（默认）
- 是

该控件只在节点类型为股票时显示。编辑已有股票节点时根据 `isHolding` 回填；保存时将“是”转换为 `true`，将“否”转换为字段缺失。

## 视觉表现

持仓股只改变股票名称，不改变节点背景、走势曲线或涨跌幅数字：

- 使用高亮紫色，避开红涨、绿跌和金银铜行业地位标识的颜色语义。
- 增加字体粗度和轻微发光阴影，提高辨识度。
- 保留现有名称截断行为。
- 异动箭头继续叠加在名称区域上方，不受持仓样式影响。

股票名称容器根据 `isHolding` 增加语义类名，样式由 CSS 统一控制，不使用内联样式。

## 模块边界

- `src/shared/types.ts`：定义持仓字段。
- `src/shared/watch-tree.ts`：校验并规范化持仓字段。
- `src/renderer/index.html` 与 `src/renderer/app/dom.ts`：声明并获取编辑控件。
- `src/renderer/features/watch/watch-controller.ts`：负责控件显示、回填和保存。
- `src/renderer/features/watch/watch-view.ts`：根据字段输出语义类名。
- `src/renderer/styles.css`：负责持仓名称视觉样式。

不新增生产模块，改动限制在现有职责范围内。

## 测试

- 配置校验测试：接受 `true`，省略 `false`，拒绝非布尔值。
- 编辑表单测试：存在“持仓股”选项，并完成回填和保存映射。
- 渲染测试：持仓股票名称包含持仓类名，普通股票不包含。
- 完整类型检查、单元测试和生产构建。
