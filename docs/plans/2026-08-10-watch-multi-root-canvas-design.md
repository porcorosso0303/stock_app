# 盯盘脑图多根画布设计

## 目标

将每个盯盘展示区从单根脑图升级为可包含多棵独立脑图的画布，并支持根节点自由定位、整树拖动重挂、原生双向滚动和以光标为中心的缩放。节点是否位于当前可视区域内，只影响用户能否看到它，不能影响行情、统计、消息和走势图数据更新。

## 非目标

- 不把股票节点提升为根节点。
- 不允许普通分类节点拖到空白处后自动成为根节点。
- 不增加秒级或逐笔行情数据源。
- 不持久化缩放比例和画布滚动位置。
- 不引入节点可视区域虚拟化。

## 方案选择

采用“多根森林 + 独立位置表”。不使用隐藏虚拟根，因为虚拟根会污染分类统计、连接线和拖拽校验语义；不改成扁平图结构，因为现有递归树操作和分类统计均建立在树结构上，全面扁平化改动过大。

## 数据模型

每个展示区保存多棵分类树和独立根坐标：

```ts
interface WatchTreeWorkspace {
  id: string;
  name: string;
  roots: WatchTreeCategoryNode[];
  rootPositions: Record<string, {
    x: number;
    y: number;
  }>;
}
```

约束：

- `roots` 中每项必须是分类节点。
- 展示区内所有根树共享同一个节点 ID 命名空间，所有节点 ID 必须唯一。
- `rootPositions` 只能引用当前 `roots` 中的节点 ID。
- 坐标必须为有限非负数，使用未缩放的画布逻辑像素。
- 缺失坐标时由布局函数生成互不重叠的默认错位位置。
- 删除根节点时同步删除位置。
- 根节点挂到分类节点下时，从 `roots` 和 `rootPositions` 中移除，原子树结构完整保留。

旧格式 `WatchTreeWorkspace.root` 和顶层兼容字段 `WatchTreeConfig.root` 在读取时迁移为 `roots: [root]`。用户现有脑图必须完整保留。保存、导入和导出统一使用多根格式；兼容镜像只用于过渡读取，不作为新业务逻辑入口。

## 纯函数与树操作

`src/shared/watch-tree.ts` 继续承载不依赖 DOM 的数据操作，但从单根参数扩展为展示区森林操作：

- 获取、更新和遍历当前展示区全部根节点。
- 跨根树查找、替换和删除节点。
- 收集全部根树中的股票 secid 和持仓股。
- 新增根分类并保存初始位置。
- 更新根节点位置。
- 将根节点整树挂到目标分类节点下。
- 保持普通分类和股票节点现有换父节点规则。

拖动重挂继续遵守：目标必须是分类；不能拖到自身或自身后代；分类和股票不能混为同级兄弟；股票始终是叶子节点。根节点拖到合法分类后变为普通分类节点；拖到非法节点后结构和位置均不改变。

## 画布渲染

`watch-view.ts` 在同一个 `.watch-graph` 中渲染所有根树。每棵根树放入带根 ID 的独立绝对定位容器，容器位置来自 `rootPositions`。树内部仍使用当前递归节点 DOM、涨跌排序、统计、走势图和异动提示逻辑。

`.watch-connectors` 仍覆盖整个逻辑画布。`watch-connectors.ts` 根据 DOM 布局绘制每棵树内部的父子连线；不同根树之间没有连接线。画布尺寸根据所有根树的逻辑坐标和渲染后尺寸动态扩展，保证位于右侧或下方的树可以通过滚动到达。根坐标不允许为负，避免节点拖出左上边界后无法找回。

刷新行情或编辑节点引起重绘时，根位置不重新自动排列，并恢复刷新前的 `scrollLeft` 和 `scrollTop`。

## 创建根节点

用户在画布空白处点击鼠标右键后可创建根分类。Controller 将菜单点击位置转换为未缩放的逻辑画布坐标，并把新分类追加到当前展示区 `roots`。如果新位置与已有根树明显重叠，按固定偏移向右下方寻找可用位置。创建新根不能覆盖现有根。

## 拖动交互

现有抓握手掌、半透明源节点和拖动 ghost 视觉继续保留。

根节点拖动有两种落点：

1. 落在画布空白处：整棵树移动到新逻辑坐标并持久化。
2. 落在分类节点上：执行重挂校验；合法时整棵根树成为目标子分类，非法时不做任何修改。

普通分类和股票继续只能通过合法目标节点重挂。它们落在空白处时不移动、不提升为根节点。

拖动时使用缩放后的命中测试，但位移量必须除以当前缩放比例后再写入逻辑坐标。切换标签页、取消指针或拖动失败时必须清理 ghost、源节点样式和 pointer capture。

## 滚动

`.watch-panel` 使用原生 `overflow: auto`：

- 普通滚轮上下滚动。
- `Shift + 滚轮` 左右滚动。
- 保留按住空白区域拖动画布平移。

标准滚轮不修改根节点坐标。滚动位置只作为 renderer 运行期状态，不写入用户数据。

## 缩放

光标位于画布内时，`Ctrl + 鼠标滚轮`调整缩放：

- 范围 `50% - 200%`。
- 每次变化 `10%`。
- 以鼠标位置为缩放中心，缩放后保持光标下的逻辑位置稳定。
- 切换展示区或重启程序后恢复 `100%`。
- 缩放不写入 `watch-tree.json`。

使用未缩放逻辑画布和缩放展示层分离的结构。节点、文字、连接线、图标和 SVG 走势图统一缩放，外层滚动占位尺寸按缩放比例同步计算，避免 CSS transform 后滚动范围错误。

当前走势图已经使用 provider 返回的全部 1 分钟分时点，不做抽样丢弃。放大后 SVG 和全部分钟点一起展开，细节距离增加但不伪造新数据；缩放不触发行情重新拉取。

## 行情与离屏更新

行情、消息和统计遍历配置数据中的全部根树，不依赖 DOM 是否可见：

- 当前视口之外的节点继续更新。
- 折叠分类中的股票继续更新。
- 当前未激活展示区继续按已有逻辑后台刷新。
- 切回标签页或滚动到离屏节点时立即展示内存中的最新行情。

不采用可视区域虚拟化。当前展示区所有节点保持渲染，行情刷新继续更新展示区状态并重绘；非当前展示区只更新各自内存状态。

## 错误处理

- 非法根坐标、重复节点 ID、股票根节点或悬空位置引用在配置校验时拒绝。
- 缺失位置不视为损坏，使用默认位置补齐。
- 非法拖动不保存、不改变 DOM 数据状态。
- 缩放和滚动只处理画布内事件，不影响应用其他模块和 Electron 菜单快捷键。
- 行情 provider 失败继续沿用同交易日有效快照保护，不因节点离屏、缩放或多根结构改变。

- 旧单根配置迁移和新格式校验。
- 多根创建、编辑、删除、导入、导出和自动保存。
- 全森林股票和持仓股遍历。
- 根节点空白拖动持久化、整树重挂和非法目标回滚。
- 普通节点空白拖动无效。
- 根位置默认布局和防重叠。
- 原生纵向滚动、Shift 横向滚动和滚动位置恢复。
- Ctrl 滚轮缩放范围、步长、光标锚定和切换标签恢复 100%。
- 缩放后连接线和根树位置一致。
- 行情刷新不依赖节点是否处于视口、折叠或激活标签页。
- 全量单元测试、TypeScript 类型检查、生产构建和 Windows 解压版部署校验。
