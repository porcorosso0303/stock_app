# 盯盘行情固定刷新提示设计

## 问题与根因

盯盘工具栏中的 `watch-status` 当前是 `watch-toolbar-status` 网格的独立一行。行情刷新开始时写入“正在刷新行情...”，结束时清空；工具栏使用自动行高，因此状态文字从空到非空会增加工具栏高度，并把下面的脑图展示面板整体向下推，形成周期性画面抖动。

## 目标

- 行情加载和刷新期间显示简短的 `⏳ 刷新中..`。
- 提示位于脑图展示面板之外的顶部工具栏。
- 提示显示或隐藏时不改变工具栏高度，不推动脑图。
- 导入、导出、消息分析等普通状态继续可见，也不能造成工具栏高度变化。
- 行情错误继续显示在数据日期旁边。

## DOM 与布局

在顶部工具栏左侧增加固定高度的标题状态行：

- “盯盘脑图”标题。
- 独立的 `watch-refresh-indicator`，内容为 `⏳ 刷新中..`，默认隐藏。
- 现有 `watch-status`，用于非行情加载状态。

标题状态行使用单行 flex 布局和固定最小高度。刷新指示器及普通状态均限制为单行并使用省略号，因此内容变化不会增加工具栏高度。展示区 `watch-panel` 的结构和滚动坐标不变。

## 控制逻辑

行情更新入口统一负责刷新指示器生命周期：

1. 通过并发保护后，显示刷新指示器。
2. 执行当前展示区或所有展示区的数据更新。
3. 在 `finally` 中隐藏刷新指示器，成功、失败和异常路径一致。

`updateWorkspaceMarketData` 不再把行情加载文字写入 `watch-status`。它仍负责更新行情错误、暂无股票提示和最终绘图。其他业务动作继续写 `watch-status`。

## 测试

- DOM/CSS 测试确认刷新指示器位于工具栏、默认隐藏，并且标题状态行为固定单行布局。
- Controller 测试确认行情更新显示和隐藏指示器，不再写入“正在刷新行情...”状态文字。
- 异常路径测试确认刷新失败后指示器仍隐藏且错误可见。
- 完成类型检查、全量测试和生产构建。
