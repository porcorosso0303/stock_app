## 构建

在 Windows PowerShell 中执行：

```powershell
npm install
npm test
npm run build
npm run dist:win
```

确认：

- 所有自动化测试通过。
- `release/` 中生成 NSIS `.exe` 安装包。
- 安装包可完成安装并打开应用。

## Codex CLI 环境

执行：

```powershell
codex --version
codex login status
```

确认已登录。

测试用户级 `PATH` 自动修复：

1. 临时从当前用户 `PATH` 移除 npm 全局目录，但不要卸载 Codex。
2. 启动应用。
3. 点击“重新检测”。
4. 确认应用找到 `codex.cmd`。
5. 确认 npm 全局目录已追加到当前用户 `PATH`。
6. 确认应用本次运行即可使用 Codex，不需要管理员权限。

## 首次调研

1. 清除应用配置，或使用新的 Windows 用户运行应用。
2. 输入一个真实 A 股标的名称。
3. 点击“调研”。
4. 确认应用弹出目录选择框。
5. 取消选择，确认任务不启动。
6. 再次点击“调研”，选择报告目录。
7. 确认任务启动，按钮变为“停止调研”。
8. 切换到“实时输出”，确认顶部固定显示动态 `working` 状态和耗时，只持续追加重要中文进展，并且只有日志区域自动滚动到最新内容。
9. 等待任务完成，确认自动切换到“调研报告”。
10. 确认动态 `working` 状态已经消失。
11. 检查报告包含来源链接和日期。
12. 点击报告中的网页来源链接，确认系统默认浏览器打开对应页面，应用窗口仍停留在报告页面。

## 调研规范

1. 打开“调研规范”标签页。
2. 确认默认规范已经加载。
3. 修改规范并点击“保存规范”。
4. 确认界面提示新规范从下一次调研开始生效。
5. 清空规范并保存，确认界面提示“调研规范不能为空”。
6. 点击“恢复初始版本”，确认编辑框恢复内嵌初始文本，并提示从下一次调研开始生效。
7. 重新打开应用，确认恢复后的初始文本仍然生效。
8. 启动一次调研，确认任务目录 `.agents/skills/research-a-share-stock/references/stock_research_spec.md` 使用恢复后的内容。

## PDF

确认：

- PDF 文件名格式为 `<标的名称>_YYYY-MM-DD_HHmmss.pdf`。
- 中文文字显示正常。
- 标题、列表、链接和表格排版可读。
- 点击“打开 PDF”可以调用系统默认 PDF 阅读器。
- 同一标的同一天再次调研时不会覆盖已有 PDF。

测试重新导出：

1. 将目标目录临时设置为不可写目录，或用开发环境模拟 PDF 导出失败。
2. 确认历史状态为“报告完成，PDF 导出失败”。
3. 恢复可写目录。
4. 点击“重新导出 PDF”。
5. 确认 PDF 生成且历史状态更新为“已完成”。

## 盯盘脑图

1. 点击左侧“盯盘脑图”，确认右侧完整工作区切换到脑图面板，调研报告区域不再显示。
2. 在空白区域点击鼠标右键，创建分类“科技股”。
3. 右键点击“科技股”分类，通过菜单添加“软件”和“硬件”两个分类。
4. 右键点击分类节点，选择“添加子股票”，输入“贵州茅台”并点击“按名称搜索股票”。
5. 从 A 股候选中选择贵州茅台，保存后确认股票节点已出现。
6. 确认股票节点显示名称、右侧走势曲线和紧贴曲线右侧的实时涨跌幅数字；曲线零轴为虚线，整条走势线和涨跌幅数字按最新涨跌幅统一显示红色或绿色，不按线段混色。
7. 左键点击展开状态的分类节点，确认子树回缩，节点右侧紧贴显示小加号；再次左键点击，确认子树展开且小加号消失。
8. 确认每个父节点与直接子节点之间使用平滑曲线连接，分叉关系清晰，且回缩后隐藏子树的连接线同步消失。
9. 在脑图展示区域按住鼠标左键拖动，确认可以向任意方向平移，拖动时光标显示为抓取状态。
10. 点击“刷新行情”，确认顶部更新时间发生变化，走势曲线和涨跌幅按最新行情更新。
11. 重启应用，确认已配置的脑图仍然存在，并且同日已拉取的走势从 `user_data/watch-quotes-cache.json` 直接恢复。
12. 检查软件根目录下存在 `user_data/watch-tree.json` 和 `user_data/watch-quotes-cache.json`。
13. 隔日启动或临时修改缓存日期后启动，确认应用重新拉取新一天走势。
14. 在断网状态下刷新，确认已有同日缓存继续显示；无缓存股票显示“暂无行情”，界面不展示虚构价格。

## 历史与取消

确认：

- 历史记录按时间倒序排列。
- 点击历史记录可重新展示 Markdown 报告。
- 运行中点击“停止调研”，状态更新为“已取消”。
- 取消后可以启动新的调研。

测试 CLI 失败展示：

1. 使用开发环境 fake Codex 模拟 CLI 失败。
2. 确认任务状态显示 Codex CLI 返回的错误。
3. 确认历史记录状态为“调研失败”。
4. 点击失败记录，确认自动切换到“调研报告”标签页并显示失败原因。

## 安全检查

确认：

- 应用没有读取或复制 Codex credential 文件。
- Codex prompt 使用 `$research-a-share-stock` skill。
- 应用使用任务目录 `.agents/skills/research-a-share-stock/` 中的内嵌 skill 副本，不要求用户全局安装 skill。
- Codex CLI 参数包含 `--search`、`-s read-only`、`-a never`。
- 股票名称只通过 stdin 传入 Codex。
- Renderer 启用上下文隔离，禁用 Node.js integration。
